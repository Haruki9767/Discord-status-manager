## Overview

**Discord Status Manager** is an Android application for creating customized Discord Rich Presence activities without being restricted to Discord's default activity presets.

Configure your activity exactly as you want it:

- Custom details and state
- Large and small images
- Custom buttons
- Elapsed and remaining timestamps
- Custom activity durations
- Optional server-powered 24/7 presence

The project is maintained by **Haruki9767 and verified contributors**.

> Discord Status Manager is an independent project and is not affiliated with, sponsored by, or endorsed by Discord Inc.

## Installation

### Android

1. Open the official [Releases](https://github.com/Haruki9767/Discord-status-manager/releases) page.
2. Download the latest official APK.
3. Install the APK on your Android device.
4. If Android blocks the installation, enable installation from unknown sources for the application you are using to install the APK.
5. Launch Discord Status Manager.

> **Security notice:** Only install APKs obtained from sources you trust. Unofficial or modified builds are not verified or maintained by Haruki9767 unless explicitly designated as official.

---

## Usage

### 01 — Authenticate

Open the application and authenticate using the supported Discord account method.

### 02 — Build Your Presence

Configure your activity using the available options:

Details
State
Images
Buttons
Timestamp
Preview

03 — Start the Presence

Apply your configuration and start the Rich Presence.

04 — Enable 24/7 Mode

If available, enable the optional server-powered mode to keep your presence running independently of the Android application.

Important: Discord Tokens

Never share your Discord account token with anyone.

This project may support authentication using a Discord user token. Automating a normal Discord user account through a personal token can violate Discord's Terms of Service and may result in account restrictions or termination.

Using a self-bot or automated user account is not officially supported by Discord.

Use this functionality only if you understand the associated risks and applicable third-party terms.

Security Rule

Treat your Discord token like a password.

If someone obtains it, they may be able to access or control your account.

For production use, prefer official Discord-supported authentication methods and APIs wherever possible.
